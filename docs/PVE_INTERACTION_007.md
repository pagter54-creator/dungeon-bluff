# PVE 지도·이벤트·증강 자원·올인 수정

- Realtime 갱신으로 지도를 다시 그릴 때 원정/층별 세로·가로 스크롤을 복원합니다. 다른 층의 지도에는 이전 층의 위치를 적용하지 않습니다.
- 지도 노드의 눌림 상태는 중앙 위치 변환을 유지합니다. 공통 버튼의 `translateY` 효과가 `translate(-50%,-50%)`를 덮어쓰던 문제를 제거했습니다.
- 이벤트 진입 시 일반 카드의 소모 상태와 전투 스킬 스택을 새로 초기화합니다. 보유 증강·유물·영구 획득 카드는 유지하며 귀검사의 포식과 그에 따른 귀참 레벨을 보존합니다. 도박사는 소멸 카드와 획득 카드를 보존한 덱에서 새 손패를 받습니다.
- 도박사 자신의 카드 버튼은 공개 손패의 배열 순번이 아니라 본인에게만 전달되는 실제 손패 ID로 제출합니다. 손패가 갱신되어 선택한 카드가 사라지면 선택을 해제합니다. 다른 참가자에게 물리 카드 ID와 덱 순서를 공개하지 않습니다.
- 전투 올인은 **1·4·7·10턴**의 고정 발동 기회입니다. 중복 실패 또는 손패 부족으로 기회를 놓쳐도 다음 발동 턴은 바뀌지 않습니다. 전투별 턴 번호를 기준으로 하며, 이벤트의 카드 판정은 전투 쿨타임을 사용하지 않습니다. 피해 공식은 유지합니다.
- 몬스터가 행동하는 턴에 PVE 일러스트의 붉은 테두리와 윤곽을 표시합니다. 공개 연출에서도 표시를 유지하며 실제 패턴 판정이 저지/대기이면 해제합니다.

## 증강 자원 UI 검증

표시값은 서버의 공개 자원 또는 명시적으로 공개한 확정 숫자 카운터만 사용합니다. 비공개 카드, 행동 계획, 과거 선택 기록을 공개하지 않습니다.

| 캐릭터 | 점검·표시 항목 |
| --- | --- |
| 마법사 | 실제 마나 최대치, 증폭/역산술 최대 변화량, 대칭·균형 스택 |
| 총잡이 | 과열, 정밀도, 약점, 전탄 출력, 정밀 사격 보존 |
| 기사 | 강인함 최대 충전, 전진 스택, 방어 |
| 도적 | 비열함, 치명타, 최저 숫자 연속, 도약, 독 |
| 광전사 | 복수, 활력, 상처 기억, 난전 |
| 무투가 | 증강으로 늘어난 연격 최대치, 기, 고양 |
| 흡혈귀 | 혈기·지배의 증강 최대치, 혈약 |
| 임프 | 저장 숫자와 증강별 최대치 |
| 예언가·귀검사·쌍둥이 | 기존 계시 최대치, 포식/귀참, 태양·달·재충전 표시 유지 |
| 도박사 | 올인 발동 턴/남은 턴과 기존 덱·행운·충전 표시 |

마법사의 `+4` 증폭은 서버 규칙대로 7마나이며, 8마나로 표시/제출하던 오류를 수정했습니다. `aug-092`/`aug-099`의 7마나 최대치도 반영합니다. 역산술은 서버 허용 범위인 ±1/±2와 결과 0~6을 유지합니다.

DB migration은 추가하지 않습니다. main의 전체 테스트·참조·workflow 검사를 통과한 변경은 기존 GitHub Actions로 Pages와 Edge Functions에 배포합니다. production 수동 명령과 production smoke는 실행하지 않습니다.
