# 도박사·몬스터·스킨·로딩 업데이트

## 적용 내용

- 도박사는 처음부터 카드 2장을 받습니다. 제출한 카드는 중복으로 무효가 되더라도 소비하고, 다음 턴을 열기 전에 무작위 카드 한 장을 보충합니다. 사이클은 없습니다. 남아 있는 6 또는 7과 같은 숫자는 보충 후보에서 제외합니다. 6과 7을 함께 들거나 1~5의 같은 숫자 두 장을 드는 것은 가능합니다. 기절 자동 제출과 혼돈 고블린의 두 장 선택에도 동일한 규칙이 적용됩니다.
- 몬스터 8종과 보스가 `monster/`의 일러스트를 사용합니다. 각각 돌진, 음파, 화살, 내려찍기, 저주, 점액, 폭탄, 물기 공격 연출을 사용합니다.
- 준비 화면은 장착한 전신 스킨을 흑백·반투명 배경으로 보여 줍니다. 이미지는 자신의 칸 안에 잘리며, 닉네임·직업·준비 상태는 앞쪽 정보 영역에 표시됩니다. 다른 플레이어의 장착 스킨도 기존 방 조회에 포함된 공개 스킨 ID로 표시합니다. 추가 폴링은 없습니다.
- 한국어 직업명은 기사로 바꾸고 `warrior` 식별자는 유지했습니다.
- 최초 접속 시 BGM 2곡과 기본 전신 스킨 8종을 우선 로드합니다. 이후 나머지 스킨·기본 크롭·몬스터·카드 치장 이미지를 백그라운드에서 로드합니다. 동시에 요청하는 수는 최대 2개입니다. 방 생성·참여·게임 시작 시 아직 필요한 이미지가 남아 있으면 진행률을 표시합니다. 실패한 이미지는 재시도하거나 돌아갈 수 있습니다. 음악 파일 오류는 게임 입장을 막지 않으며 자동재생 제한도 유지합니다.

## 서버 적용

현재 연결된 프로젝트 `dvpisuvyeyqwhewfbnls`에 `202609220002_gambler_skins.sql`을 적용하고 `game-api`를 배포했습니다. 기존 계정·재화·보유 스킨은 보존했습니다. `account-api`는 DB의 뽑기 목록을 읽으므로 이번 변경에는 재배포가 필요하지 않습니다.

이미 진행 중인 원정은 시작 시 저장된 캐릭터 규칙을 유지합니다. **새 도박사 규칙은 새로 시작하는 원정부터 적용됩니다.**

## GitHub Pages 업로드

현재 작업 폴더의 아래 항목을 저장소의 같은 상대 경로에 반영합니다. Pages 자동 업로드는 수행하지 않았습니다.

- `index.html`
- `src/` 전체 (새 CSS·로더·몬스터 파일 포함)
- `skin image/` 전체 PNG (32개 전신, 8개 기본 크롭)
- `monster/` 전체 PNG (파일명 대소문자 유지)

기존 `styles.css`, `assets/`, `config.js`, `bgm_lobby.mp3`, `bgm_dungeon.mp3`, 선택적 `sfx_*.mp3`는 계속 필요합니다. 새 저장소에 올리는 경우 이 항목도 함께 올립니다. `.update-*`, `node_modules`, `supabase/.temp`, 테스트 결과 파일은 웹 배포 대상이 아닙니다.

## 검증

JavaScript/TypeScript 문법·로컬 참조 검사 및 자동 테스트 110개 통과. 카드 보충/소비, AI 원정, 24종 중복 없는 뽑기와 골드 차감, 이미지 경로, 전투 포즈 규칙, 로딩 동시 요청 제한·실패·재시도 포함. 요청에 따라 브라우저 플레이 테스트는 하지 않았습니다.

## 전투 포즈 파일 규칙

장착 스킨의 기본 파일과 같은 폴더에 `{스킨ID}_A.png`를 두면 공격할 때, `{스킨ID}_D.png`를 두면 피격할 때 자동으로 사용합니다. 예: `berserker2.png`, `berserker2_A.png`, `berserker2_D.png`. 파일이 없거나 불러오기에 실패하면 기본 일러스트를 유지합니다. 현재 존재하는 `berserker0~3`의 A/D 8개는 백그라운드 로딩 목록에도 포함했습니다. 앞으로 추가하는 파일은 별도 코드 수정 없이 해당 스킨의 첫 공격/피격 때 확인하고 이후 캐시합니다.

공격·피격 연출 중 일러스트 표시 영역을 14px 위로 옮깁니다. 기절하면 해당 장착 스킨의 `_D` 일러스트를 계속 표시하고 부활하면 기본 일러스트로 되돌립니다. 재접속 후 복원된 기절 상태도 같은 방식으로 표시합니다.
