# 직업 밸런스 패치

- 예언가: 1/2/3/4/5. 계시 발동 시 사용 카드 개체 1장 무작위 복구. 평소 중복 시 +1중첩, 계시 사용 턴에는 통과 시에만 +1중첩.
- 도박사: 관망에서 1~4 한 장, 직전 관망 숫자 제외. 첫 관망은 네 숫자 모두 후보. 중복으로 진행도가 사라지지 않으며 2회 통과 후 다음 손패부터 일반 모드. 진행도는 노란 두 칸.
- 총잡이: 사이클마다 전탄발사 1회. 중복 실패 시 HP −1, 이 피해로 기절하면 기존 −10점/−3G와 다음 턴 자동 선택 적용. 오발은 몬스터의 추가 공격처럼 보이지 않도록 캐릭터 위치에서 표시.
- 도적: 모든 비전투 방의 단독 최저 유효 카드에 손버릇 +5점/+2G. 전투에서는 비열한 일격으로 피해를 5로 고정. 기존 봉인·장갑·포식의 공격 무효는 유지.
- 마법사: 1/2/3/4/4. 초기 마나 0, 첫 턴 시작 시 1, 매 턴 +1, 최대 4. 마나 2/4로 실제 카드 숫자 +1/+2. 2~3마나 버튼은 미사용→+1→취소, 4마나는 미사용→+1→+2→취소. 예약은 클라이언트에서 변경하며 확정된 비용만 서버 판정 때 한 번 차감. 원본 카드 개체를 소비하고 공개·중복·몬스터·이벤트 판정에는 증폭된 숫자를 사용.
- 기사: 2/3/4/5/5. 사이클 시작마다 강인함 +1충전, 최대 2. 첫 사이클은 1충전. 저장한 두 충전을 같은 사이클의 서로 다른 턴에 사용 가능.
- 모험가: 기존 골드 보너스 유지. 전투에서 중복 없이 통과하면 피해와 별도로 점수 +1. 처치 기여 계산에는 영향을 주지 않음.

## 연출

기존 카드 뒤집기, 중복 소멸, 강인함 소멸 저항, 투사체, 피격 포즈, 화면 흔들림과 음향의 순서·타이밍은 유지합니다. 변경된 스킬은 기존 스킬 발동 효과·효과음에 연결하고 증폭 표시를 실제 숫자 변화에 맞췄습니다.

브라우저 플레이 테스트는 생략하고 서버 규칙·DB 통합·UI 출력·문법 검사를 수행합니다.
