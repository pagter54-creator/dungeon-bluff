## 의미별 추가 검토

- 다음 공격: BETA에 명시된 '다음 유효 공격'은 그대로 유지한다. 소비 경계가 비어 있는 카드는 해당 직업 질문에 남긴다.
- 복구: 원문과 BETA가 충돌하는 6장은 Q04, 카드 선택자는 Q08에서 다룬다. 대상 부재 시 소모 규칙은 원문에 없으므로 카드별 추가 명세가 필요하다.
- 지연 효과: 전투 종료 reset이 명시된 것은 기존 005R 정책을 따른다. 다음 전투 이월은 추측하지 않는다.
- EXP·Gold: 명시된 획득 출처만 적용한다. 출처가 빠진 카드는 직업 질문에서 카드별로 확정한다.
- 유물: 중복·소지 한도는 Q05/Q06.
- 스택·자원: 명시된 cap과 class canonical을 적용한다. overflow 보너스나 refresh 효과는 추가하지 않는다.
- 피해·회복: BETA와 원문이 충돌하는 항목은 Q01–Q04. 추가 타격은 별도 피해 이벤트인지 카드별 확인한다.
