## 공격 순서

일반 몬스터 8종은 모두 3턴마다 기본 공격을 합니다. 보스는 모두 2턴마다 행동하며 기본 공격부터 시작합니다.

보스 방 진입 기준 **2턴 기본 공격 → 4턴 특수 패턴 → 6턴 기본 공격 → 8턴 특수 패턴** 순서입니다. 특수 패턴이 발동한 다음 턴에 효과가 적용됩니다. 특수 패턴을 사용하는 턴에는 기본 공격을 함께 하지 않습니다. 기본 공격 피해는 모두 1이며, 처치한 턴에는 보스의 남은 행동이 취소됩니다.

| 몬스터 | 기본 공격 | 보스 특수 패턴 |
| --- | --- | --- |
| 철갑 멧돼지 | 가장 높은 유효 카드 | 돌진 준비: 다음 턴 유효 피해 합계가 8 미만이면 장갑 획득. 그다음 턴 첫 유효 공격을 0으로 차단 |
| 메아리 박쥐 | 중복으로 무효된 플레이어 | 잔향: 발동 직전 턴의 중복 숫자를 기록. 다음 턴 그 숫자 카드의 효과값 -1 |
| 비겁한 사냥꾼 | 가장 낮은 유효 카드 | 표적 지정: 현재 점수 1위에게 표식. 다음 턴 제출 즉시 그 숫자를 참가자 모두에게 공개 |
| 처형 골렘 | 숫자 4 이상 | 봉인 명령: 숫자를 미리 예고. 다음 턴 해당 숫자의 효과 0, 소비·중복 판정은 유지 |
| 저주받은 예언자 | 홀수 카드 | 뒤틀린 예언: 홀수/짝수를 미리 예고. 다음 턴 해당 유효 카드 효과값 -1 |
| 굶주린 슬라임 | 숫자 2 이하 | 포식: 다음 턴 가장 낮은 유효 카드 1장의 효과를 0으로 만들고 그 원래 숫자만큼 회복, 최대 3 |
| 혼돈 고블린 | 짝수 카드 | 뒤죽박죽: 다음 턴 서로 다른 카드 인스턴스 2개를 선택하고 서버가 1개를 무작위 제출 |
| 탐욕의 미믹 | 현재 점수 1위 | 황금 미끼: 다음 턴 최고 유효 카드에 골드 +3. 탐욕 표식을 부여해 다음 기본 공격의 우선 대상으로 삼음 |

## 세부 판정

- 멧돼지 예: 4턴 예고 → 5턴 피해 합계 검사 → 8 미만이면 6턴 첫 유효 공격을 방어합니다. 8 이상이면 장갑을 얻지 못합니다. 장갑은 해당 턴에만 유효합니다. 공격 순서는 기존과 같이 카드 원래 숫자 오름차순입니다.
- 박쥐가 4턴에 특수를 쓰면 3턴의 중복 숫자를 기록합니다. 해당 숫자가 다음 턴에 다시 중복되더라도 효과값 감소 자체는 적용되며 중복 카드는 여전히 공격하지 못합니다.
- 효과값 감소는 0 아래로 내려가지 않습니다. 중복 판정·홀짝·최고/최저 숫자 판단은 스킬 적용 전 원래 카드 숫자를 사용합니다.
- 봉인·포식·장갑은 증폭·광전사 추가 피해가 있어도 해당 공격을 0으로 만듭니다. 봉인된 카드도 같은 숫자의 다른 카드를 중복으로 무효화할 수 있습니다.
- 사냥꾼의 점수 1위가 여러 명이면 모두 표식 대상입니다. 미제출 카드 숫자는 노출하지 않고, 대상이 제출한 뒤에만 공개합니다. 다음 턴 종료 후 공개 효과가 사라집니다.
- 슬라임은 포식한 카드의 원래 숫자로 회복하며, 다른 유효 카드의 공격 전에 회복합니다. 최대 HP를 넘지 않고, 유효 카드가 없으면 회복하지 않습니다.
- 뒤죽박죽은 숫자가 같아도 서로 다른 카드 인스턴스라면 두 장 선택할 수 있습니다. 실제 제출된 한 장만 소비합니다. 남은 카드가 한 장이면 그 한 장을 제출합니다. AI·기절 자동 제출에도 같은 무작위 선택을 적용합니다. 요청 재시도는 이미 결정된 카드를 다시 뽑지 않습니다.
- 탐욕 표식은 다음 기본 공격 1회에 사용하고 제거합니다. 표식 대상은 기존 점수 1위 대상보다 우선합니다. 골드 +3에는 기존 모험가의 골드 보너스가 적용되어 모험가는 +4G를 받습니다.
- 특수 패턴과 장갑·표식은 보스별 상태에 저장되며 새 원정/다음 방으로 이어지지 않습니다. 표식 공개를 제외한 비밀 제출 카드는 다른 플레이어에게 노출하지 않습니다.

## 전멸 보상

누적 기절 8회로 전멸했을 때 **전멸 당시 도달한 스테이지**를 기준으로 원정 점수와 Run Gold를 정산합니다. 해당 스테이지를 클리어할 필요는 없습니다.

| 도달 스테이지 | 정산 배율 |
| --- | --- |
| 1~4 | 0배 |
| 5 | 0.2배 |
| 6 | 0.3배 |
| 7 | 0.4배 |
| 8 | 0.5배 |
| 9 | 0.6배 |
| 10 (보스) | 0.7배 |
| 보스 클리어 | 1배 |

예를 들어 8스테이지에서 원정 점수 99점·Run Gold 57G로 전멸하면 49점·28G를 정산합니다. 소수점은 버리며 전멸 정산의 음수 점수·골드는 0으로 처리합니다. 기절 순간의 -5점/-2G를 먼저 반영한 잔액에 배율을 적용합니다.

등록 계정은 정산 골드를 Account Gold로 지급받고 정산 점수를 누적 원정 점수에 기록합니다. **전멸 시 영구 RP·클리어 횟수·클리어 순위 횟수는 변하지 않습니다.** 클리어 시 기존 순위별 RP 및 클리어 통계를 적용합니다. 게스트는 결과 화면만 정산하며 영구 저장하지 않습니다.

서버는 스테이지에서 배율을 다시 계산합니다. 결과 저장·영구 골드 지급은 같은 트랜잭션에서 한 번만 처리하므로 새로고침이나 응답 재시도로 중복 지급되지 않습니다. 중도 이탈·방 만료·전원 퇴장은 전멸 보상의 대상이 아닙니다. 원정 시작 시 등록 계정이었던 참가자만 지급 대상으로 유지합니다.
