# Character Update 0.1

대기실에서 자신의 캐릭터를 선택합니다. 호스트는 AI 캐릭터도 변경할 수 있습니다. 게임 시작 후에는 변경할 수 없습니다. 같은 숫자도 고유 card_id로 구분하며, 모든 플레이어의 5칸 카드 풀을 공개하고 사용한 자리에 OFF를 표시합니다. 선택·제출한 카드는 턴 공개 전 다른 사람에게 노출하지 않습니다.

| 캐릭터 ID | 덱 | 스킬 |
| --- | --- | --- |
| adventurer | 1,2,3,4,5 | 양수 골드 보상마다 +1G |
| warrior | 1,2,3,5,5 | HP 1에서 첫 피해 전체 무효. HP 2 이상으로 회복해야 재충전 |
| rogue | 1,1,3,4,5 | 보물·이벤트의 최저 유효 원본 숫자라면 +2G / +5점 |
| mage | 1,2,3,4,5 | 사이클당 1회 제출 시 증폭 선택. 유효 효과값 +2, 중복 무효여도 횟수 소비 |
| berserker | 1,2,4,4,5 | 중복 시 HP 1 회복(인원수 무관). 유효 공격 효과 +1, 명중 시 HP 1 소모(최소 HP 1) |
| seer | 1,2,3,3,5 | 마지막 카드 중복 시 다음 한 턴 함께 중복된 상대의 제출 숫자를 본인만 확인 |

| gambler | 무작위 손패 2장, 사이클 없음 | 한 장 소비 후 다음 턴 전에 1~7 중 보충. 손에 남은 6·7과 같은 숫자는 제외. 6·7 사용 직후 보충은 1~5만. 모두에게 공개 |

중복 판정은 보정 전 숫자로 합니다. 마법사 효과값은 전투 피해와 비전투 효과에 적용됩니다. 광전사 보정은 전투만 적용됩니다. 처치 턴에는 모든 유효 카드의 온전한 피해를 계산하고 최고 실제 피해자 한 명에게 +10점(초록색)과 3G를 지급합니다. 보정으로 최고 피해가 같아지면 서버 난수로 선정합니다.

임프는 강탈 전 점수 스냅샷을 기준으로 함께 겹친 모든 양수 점수 상대를 대상으로 합니다. 여러 임프가 같은 대상을 골라도 스냅샷의 양수 잔액을 넘겨 강탈하지 않습니다. 기절 손실로 생긴 음수 점수는 강탈하지 않습니다.

부활 체력은 **3**이며, 파티 누적 기절 **8회**에 원정이 실패합니다. 기절 -10점/-3G와 최대 HP 3은 유지합니다.

점술사의 비공개 숫자는 인증된 소유자 응답의 privateState에만 포함합니다. 공용 세션 상태와 Realtime에는 넣지 않습니다. 일반 AI는 턴 시작에 공개 정보만으로 결정합니다. 계시 중인 점술사 AI는 대상 인간의 제출을 기다린 뒤 허용된 숫자만 참고합니다. 계시는 다음 턴 종료 후 사라집니다.
