# 프로토타입 콘텐츠 규칙

명세서의 콘텐츠 ID를 그대로 사용합니다. 상세 패턴이 첨부되지 않은 부분을 구현한 v0.1 기본값입니다. UI는 서버가 제공하는 규칙과 예고 문구를 표시합니다.

## 공통

- 캐릭터 8종과 스킬은 `CHARACTERS.md` 참고. `default_001`은 기존 진행 원정 호환용입니다.
- 실제 게임은 DB의 `characters` 정의를 읽고 원정 시작 시 스냅샷을 저장합니다. 진행 중 정의를 편집해도 해당 원정의 덱은 바뀌지 않습니다.
- 중복 카드도 소비. 남은 카드가 0장이 되면 해당 캐릭터 덱을 다시 받습니다.
- 유효 카드: 해당 턴에 자기 혼자 낸 숫자. 같은 숫자가 2~4장 있으면 전부 무효.
- 일반 HP = `round(31 × (1 + 0.07 × (stage_index - 1)) × hp_multiplier)`.
- 보스 HP = 같은 공식에 보스 배율 `2.0`을 추가한 뒤 반올림.
- 플레이어 피해 기본값 1, 최대 HP 3. 방어/방어력 시스템은 없습니다.
- 공격 직전 턴에는 UI에 `이번 턴 공격`과 대상 조건을 표시합니다.
- 보스 또는 몬스터가 이번 카드 피해로 죽으면 반격하지 않습니다.
- 처치 턴에도 모든 유효 카드가 숫자만큼 피해를 주며, 초과 피해도 점수에 포함합니다. 최고 피해자에게 추가 +10점과 기존 처치 골드 3G를 줍니다. 스킬 보정 후 최고 피해 동점은 서버 난수로 한 명을 선정합니다.
- 기절할 때마다 점수 5점, 골드 2G를 차감합니다. 점수·골드는 음수가 될 수 있습니다. 기절 중 추가 피해로 중복 차감하지 않습니다.
- 기절 후 자동 제출 턴이 끝나면 HP 3으로 복귀합니다. 회복실 효과가 이 기절 복귀 체력을 바꾸지는 않습니다.
- `유효 최고/최저`와 달리 `4 이상`, `2 이하`, `홀수`, `짝수` 공격은 중복 여부와 상관없이 제출한 숫자를 기준으로 합니다.

## 비전투 방

성공 보상은 별도 표시가 없으면 유효 카드를 낸 플레이어에게 지급합니다. 중복 카드는 보상, 회복, 성공 합계에 참여하지 않습니다. `전원` 효과는 중복 여부와 관계없이 파티에 적용되지만, 기절 중에는 피해·회복 면역 규칙을 지킵니다.

무효 카드만 남으면 성공 보상이 없습니다. 회복은 최대 HP 3을 넘지 않습니다. 비전투 방은 판정 후 다음 stage로 이동합니다.

## AI

공통 입력은 공개 `state`와 자신의 player 상태뿐입니다. `turn_submissions`를 전달하는 인자가 없습니다.

| ai_type | 선택 기준 |
| --- | --- |
| balanced | 상대 남은 카드 기반 중복 확률, 예상 유효 피해, 방 합계/카드 수 조건, 회복 필요, 막타, 공격 대상 위험, 높은 카드 보존 |
| greedy | 유효 높은 숫자·보상과 막타 우선, HP 위험 비용 축소 |
| cautious | 공격 대상 위험 비용 확대, HP 1 또는 누적 기절 7에서 크게 회피 |
| blocker | 공개된 최근 3턴 카드와 남은 카드로 선두 숫자 추정, 해당 숫자 가중치 증가 |
| chaotic | 합법 카드 무작위 중심, HP 1일 때 위험 카드 확률 소폭 감소 |

누적 기절 7회에서는 모든 성향이 생존 비중을 높입니다. 가중 무작위 선택이므로 항상 최적 행동을 하는 AI는 아닙니다.

## 확장

- 캐릭터: `characters` 행 추가. 현 UI는 선택 기능 없이 `default_001`을 사용합니다.
- 몬스터: `MONSTERS`에 기존 target selector를 조합한 정의를 추가하면 stage 생성기에 자동 포함됩니다. 새로운 공격 방식이면 엔진의 `targetsFor`를 확장합니다.
- 비전투: `ROOMS`에 기존 resolver를 조합한 정의를 추가하면 자동 포함됩니다. 새 규칙 유형이면 엔진의 비전투 resolver 분기를 확장합니다.
- 이벤트 로그: `type`, `turnIndex`, `stageIndex`, `cards`, `effects`, 전후 공개 상태를 기록합니다. 미래의 기여도 시스템은 `effects`에 새 type/필드를 추가할 수 있습니다.
