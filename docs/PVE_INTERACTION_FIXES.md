# PVE 투표·제출·전투 연출

지도에서 각 경로의 투표자 이름을 실시간 상태에 맞춰 표시합니다. AI를 제외한 모든 인간 참가자가 연결된 다음 방에 투표하면 즉시 기존 최다 득표·동률 판정으로 이동합니다. 과반수, 시간 초과, 단일 경로만으로는 이동하지 않습니다. 연결이 끊긴 인간 참가자도 재접속 후 투표해야 합니다. Realtime 알림은 기존 `pve_run_updated`를 사용하며 연결 실패 시 기존 5초 조회로 복구합니다.

각 플레이어의 스킬 이름을 누르면 해당 플레이어가 획득한 증강 이름과 효과를 함께 표시합니다. 같은 캐릭터를 선택한 참가자도 플레이어 ID로 구분합니다. 미선택 증강 후보나 다른 플레이어의 비공개 카드는 공개하지 않습니다.

전투 연출의 중복 방지는 원정·층·방·턴을 함께 구분합니다. 이전에는 원정 전체에서 턴 번호만 비교하여 새 방의 낮은 턴 번호를 건너뛰었습니다. 층 전환 결과에도 원래 전투의 식별자를 유지하며, 다음 방 진입 시 이전 보스 결과를 제거합니다. 연출 중 도착한 결과는 대기열에 보관하고 순서대로 재생합니다. 오래된 run 버전의 응답은 최신 상태를 덮어쓰지 않습니다.

카드 판정이 필요한 보상 방과 이벤트 방은 제출 컨트롤을 숨기는 사용자 지정 선택기 CSS에서 제외합니다. 카드 미선택 시에는 버튼을 비활성화하고, 제출 완료·행동 불가 상태는 기존 대기 표시를 유지합니다. 상점·휴식처는 해당 방의 기존 전용 동작을 사용합니다.

동시 제출 시 정상적으로 발생할 수 있는 `STATE_CONFLICT`는 최신 상태를 받으면 같은 방·같은 턴에서 최대 3회 재시도합니다. 재시도는 같은 action ID를 사용하여 중복 적용을 방지합니다. 방·층·턴·단계가 바뀐 경우에는 오래된 선택을 적용하지 않고 다시 선택하도록 안내합니다. 서버의 버전 비교와 DB 원자적 커밋은 그대로 유지합니다.

DB migration은 추가하지 않습니다. 테스트와 참조·workflow 검사를 통과한 main 변경은 기존 GitHub Actions에서 Pages와 game-api를 배포합니다. production smoke는 실제 계정·방·게임 상태를 생성하므로 일반 배포에서 실행하지 않습니다.
