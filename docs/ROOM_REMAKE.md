# 원정 리메이크 배포 안내

이번 버전으로 새로 시작하는 원정에 적용됩니다. 진행 중인 구버전 원정은 기존 규칙을 유지합니다.

- 일반 전투 4회, 이벤트 5회, 마지막 보스 1회. 전투/이벤트가 세 번 연속 나오지 않습니다.
- 방 종료 후 네 명의 변화량과 잔향을 간단히 표시합니다. 인간 플레이어 전원이 준비하면 다음 방으로 이동하고 AI는 자동 준비합니다.
- 결산 배경은 테두리 없이 좌우가 투명해지는 검정색입니다. 잔향·보상의 긴 설명은 상세창으로 확인합니다.
- 잔향은 파티 1개, 개인별 1개 슬롯입니다. 같은 슬롯의 새 잔향은 이전 잔향을 교체합니다. 대상 방까지 유지되며 사용하거나 해당 방이 끝나면 사라집니다.
- 소량 골드 2G, 대량 골드 6G. 제단은 즉시 4G 또는 다음 전투 생존 시 7G입니다. 기존 직업의 골드 보너스는 유지합니다.
- 상인은 유효 카드 1~2로 지도 1G, 3~4로 주사위 2G, 5 이상으로 부적 3G을 제안합니다. 구매를 거절할 수 있습니다.
- 고대의 문은 가능한 경로 중 인간 플레이어의 투표로 결정하며 동률이면 무작위입니다.
- 선두/주사위 사용자는 제출 후 현재 카드를 확정하거나 한 번 변경합니다. 확정 전에는 자동 판정하지 않습니다.
